## 🤔 为什么做这个

用过市面上的计划软件，你会发现两个共同的死穴：

| 痛点 | 传统软件的表现 |
|------|----------------|
| **死板** | 逼你填一堆表单手动排期，改一个计划要重新拖拽半天 |
| **焦虑制造机** | 「逾期警告」红字轰炸——计划赶不上变化是常态，软件却只会催债 |

真实的学习过程是**动态的**：今天没做完、状态崩了、考前发现学不完……这些才是常态。
计划工具应该跟着人走，而不是让人伺候计划。

**myProgress 的答案**：

- 🗣️ **一句话开工** —— 只说三件事：目标 + 截止日 + 每天能学多久（含休息）。永不手动排期；
- 📋 **材料零负担** —— 粘贴目录，或一句「备考公考用粉笔 5000 题」即可，不联网、不爬虫；
- 🔁 **顺延无负罪感** —— 没做完自动合并顺延到明天，文案里禁止出现「逾期」；
- 🚨 **预警不隐瞒** —— 「考前学不完」在数学上成立时立即预警 + 给出砍内容建议，但**永远保留「不砍」选项**，决定权在用户。

□ 刷题实操：资料分析-增长率 练习题 15 道（纯学习 20 分钟）

### 3️⃣ 动态调整 —— 晚上一句话，明天自动重排

睡前发一句「今天只听了视频没刷题」，Agent 自动识别完成度、顺延剩余量、合并到明天——剩余任务块连分钟数都精确缩小（25 分钟看了一半 → 顺延 13 分钟）。

### 4️⃣ 晚间提醒 —— 到点推给每个用户

独立定时脚本每天 20:00 遍历所有会话，写入晚间汇报提醒。挂了、重启了、重复跑了都不会重复打扰（见下方「双重幂等」）。

**分工铁律**：LLM 只做「理解与表达」（对齐表、状态提取、文案），排程/切块/顺延/预警触发**全部是纯 Python**，可离线单元测试。每条用户消息只允许一次 LLM 调用。

## 💡 设计亮点

### 1. 单调用意图路由

`stream_extract` 在**一次 LLM 调用**里同时完成三件事：判断意图（建计划 / 晚间汇报 / 抱怨太重 / 确认砍单…）+ 结构化提取状态 + 生成回复文本。失败时自动降级到关键词匹配兜底——LLM 挂了系统也不会瘫痪。

### 2. 基于自然语言的动态配置

用户的偏好不是存配置项，而是直接说人话：「太重了」「今天没时间」。Agent 识别后自动下调容量画像（如每日 120 → 84 分钟，×0.7）并重排后续计划——**配置即对话**。

### 3. 双重幂等定时提醒

`evening_reminder.py` 的防重复设计：

1. **DB 层幂等**：`user_states.last_reminded_at` 记录当天已提醒，写库前先查；
2. **脚本层幂等**：整个 CLI 可随意重跑，同一用户同一天绝不重复提醒。
   外部定时器（cron / 自动化平台）怎么误触发都不怕。

## 🚀 本地运行

### 环境要求

- Python 3.11+
- 一个 OpenAI 兼容网关的 API Key（默认适配 DeepSeek）

### 三步启动

```bash
# 1. 安装依赖（已锁定版本）
pip install -r requirements.txt

# 2. 配置环境变量：复制模板为 .env 并填入你的 Key
copy .env.example .env        # Windows
cp  .env.example .env         # macOS / Linux

# 3. 离线冒烟测试（无需 Key）→ 启动
python smoke_test.py
uvicorn app:app --reload      # 打开 http://127.0.0.1:8000
```

### 环境变量

写入项目根 `.env`（模板见 [.env.example](.env.example)），或直接用环境变量（优先级更高）：

| 变量 | 必填 | 说明 |
|------|:---:|------|
| `LLM_API_KEY` | ✅ | OpenAI 兼容网关的 API Key（默认 DeepSeek） |
| `LLM_BASE_URL` | — | 网关地址，以 `/v1` 结尾，默认 `https://api.deepseek.com/v1` |
| `LLM_MODEL` | — | 默认 `deepseek-chat` |
| `DB_PATH` | — | SQLite 文件路径；云部署时指向持久化卷 |

> 🔒 `.env` 与 `*.db` 均已在 `.gitignore` 中排除，不会进入版本库。

### 测试

```bash
python smoke_test.py        # 离线：排程 / 顺延 / 容量下调 / 预警砍内容 4 大场景，25 项检查
python llm_smoke_test.py    # Part A 离线结构链路；Part B 联机（需 Key）
```

### 定时提醒（可选）

```bash
python evening_reminder.py          # 正式写库；加 --dry-run 只看不写
```

## ☁️ 部署到 Render

1. **Web Service**：Build Command `pip install -r requirements.txt`，Start Command `uvicorn app:app --host 0.0.0.0 --port $PORT`；
2. 环境变量在 Dashboard 填（**不要写进代码**）；
3. **必须挂持久化卷**：免费实例磁盘是临时的，`DB_PATH` 指向挂载目录（如 `/var/data/agent.db`），否则每次部署丢光所有用户数据；
4. Health Check Path 可用 `GET /`；
5. 定时提醒用 Cron Job 服务跑 `python evening_reminder.py`，挂**同一个**持久化卷。
